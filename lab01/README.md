## What I learned today

_Write 2–3 sentences in your own words: what happens between typing a URL and seeing the page?_

When you enter a URL, the browser asks a DNS server for the website’s IP address. It then connects to that server, sends an HTTP request, and receives the page’s HTML and related resources. 
The browser processes and renders those resources, then displays the finished page.
